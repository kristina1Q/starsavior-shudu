# 凑十游戏（苹果游戏 / Fruit Box）全自动消除脚本

本脚本专为“鼠标按住框选数字，框内数字总和为 10 即消去”的拼图游戏打造。

---

## ✨ 核心特性

1. **OCR与棋盘自适应定位**
   - 采用标准字形多尺度比对技术，实测数字 1~9 识别准确率 **100%**。
   - 自动检测游戏棋盘（10 行 × 15 列），完美适配全屏、窗口化与多分辨率（如 1080P、2K、2.5K 屏幕及不同缩放比例）。
   - 附带手动标定功能，2 秒即可完成任意自定义界面的坐标保存。

2. **跨区域长方形框选算法**
   - 消除后的格子归零，后续框选支持**直接跨越空白区域**进行消除。
   - 搭载**二维前缀和与束搜索（Beam Search）算法**，提前规划最优消除路径，消除率远超普通人类玩家。

3. **极速高精鼠标模拟**
   - 基于 Windows 底层 `user32.dll` 实现平滑微步拖拽，保证游戏引擎 100% 判定成功。
   - 框选边缘智能外延，杜绝因边缘卡点导致的漏选。

4. **全局安全急停**
   - **全局停止键：`/` 键**（主键盘的 `/?` 键与小键盘的 `/` 键均可）。
   - 全局底层监听，响应时间 < 5ms，按下瞬间立即释放鼠标并安全退出。

---

## 🚀 快速开始

### 方式一：双击启动（最简便）
直接双击运行文件夹下的 **`run.bat`**。

### 方式二：命令行启动
打开终端进入该目录执行：
```powershell
python main.py
```

---

## 🎮 操作菜单说明

启动程序后将看到交互式主菜单：

- **`[1] 一键自动识别并消除 (单局执行)`**
  - 脚本将自动截屏、定位棋盘、打印当前数字矩阵并计算最优消除方案。
  - 倒计时后自动操控鼠标完成全盘拖拽消除。
- **`[2] 全局热键挂机模式 (按 F8 触发, / 停止)`**
  - 启动后脚本在后台静默监听。
  - 当你在游戏中进入关卡时，按一下 **`F8`** 键即可自动完成消除。
  - 任何时刻按下 **`/`** 键可立即急停退出。
- **`[3] 测试识别当前屏幕 (只显示数字矩阵，不动鼠标)`**
  - 用于测试当前游戏界面能否被精准识别。
- **`[4] 手动标定棋盘坐标 (备用方案)`**
  - 引导你在左上角和右下角各点击一次，精确保存棋盘像素位置。

## ⚙️ 配置文件说明 (`config.json`)

```json
{
  "rows": 10,
  "cols": 15,
  "drag_speed_ms": 25,     // 单次鼠标拖拽耗时（毫秒，越小越快）
  "move_interval_ms": 40,  // 每次消除之间的间隔时间（毫秒）
  "hotkey_start": "F8",    // 热键模式启动键
  "hotkey_stop": "/",      // 全局紧急停止键
  "saved_bbox": null       // 标定坐标缓存
}
```
